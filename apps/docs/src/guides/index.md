# Guides

Choose the task closest to the product behavior you are building. Each guide
connects the public SDK surface to the custody, policy, or lifecycle boundary
that makes the operation safe.

- [Authentication](/guides/authentication): choose passkeys, email OTP, or a
  deliberate step-up method.
- [Embedded wallets](/guides/embedded-wallets): keep wallet operations at an
  isolated origin.
- [Policies and mandates](/guides/policies-and-mandates): bind authority to a
  typed operation.
- [Wallet sessions and signing lanes](/guides/wallet-sessions-and-signing-lanes):
  carry exact session identity into signing.
- [Delegated agents](/guides/delegated-agents) and [linked
  devices](/guides/linked-devices): add narrow authority without sharing an
  existing credential.
- [Recovery, export, and rotation](/guides/recovery-export-and-rotation): treat
  high-impact account changes as fresh operations.
- [Theming](/guides/theming): align app-owned and wallet-owned surfaces.

New integrations should complete [Start here](/) before using
the advanced guides.
